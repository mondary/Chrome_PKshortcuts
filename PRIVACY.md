# Privacy Policy

Last updated: 2026-10-01

PK Chrome Shortcuts is a Chrome extension that provides keyboard shortcuts and tab/window utilities inside Google Chrome.

## Data collection

PK Chrome Shortcuts does not collect or store personal data on the developer's servers. When you explicitly request a translation, the selected text (up to 1,500 characters) is sent to Google Translate. If that request fails, or if you choose MyMemory-only mode, the selected text is sent to MyMemory (api.mymemory.translated.net) to provide the translation. These services receive the text and process it under their own privacy terms. The extension does not send other page content for translation.

The extension does not use analytics, advertising trackers, remote logging, or external databases.

## How the extension works

The extension uses Chrome extension APIs locally on your device to:

- manage tabs and windows
- open Chrome internal pages such as bookmarks, history, downloads, settings, and shortcuts
- react to keyboard shortcuts and optional click gestures
- display a badge with the current number of open tabs
- translate selected text only when you invoke the translation feature; translation requests go to Google Translate, with MyMemory as fallback, or to MyMemory alone if selected

## Website data and page access

The extension is allowed to run on webpages because it provides shortcut and navigation features that depend on the current tab and user interaction on links.

Page access is used locally on your device for shortcut features. The only page content sent externally is text you explicitly select and submit for translation, as described above. Browsing history, form inputs, and other webpage contents are not sent by the extension.

## Permissions

The extension uses the following Chrome permissions:

- `tabs`
- `windows`
- `activeTab`
- `scripting`
- host access on pages needed for the extension features

These permissions are used only to provide the extension's local functionality.

## Data sharing

The extension does not sell user data. Selected text is shared only with the translation provider needed to fulfill a translation you request (Google Translate and/or MyMemory); it is not sent to the developer. No analytics or advertising data is collected.

## Contact

If you have questions about this privacy policy, contact the developer through the support or contact details associated with the extension listing.
