Privacy Policy

PK Chrome Shortcuts is a Chrome extension that provides keyboard shortcuts and tab/window utilities inside Google Chrome.

Data collection

PK Chrome Shortcuts does not collect or store personal data on the developer's servers. When you explicitly request a translation, the selected text (up to 1,500 characters) is sent to Google Translate. If that request fails, or if you choose MyMemory-only mode, the selected text is sent to MyMemory (api.mymemory.translated.net). These services receive the text to provide the translation and process it under their own privacy terms.

The extension does not use analytics, advertising trackers, remote logging, or external databases.

How the extension works

The extension uses Chrome extension APIs locally on your device to:

  • manage tabs and windows
  • open Chrome internal pages such as bookmarks, history, downloads, settings, and shortcuts
  • react to keyboard shortcuts and optional click gestures
  • display a badge with the current number of open tabs
  • translate selected text only when you invoke translation; requests go to Google Translate with MyMemory as fallback, or MyMemory alone if selected

Website data and page access

The extension runs on webpages because it provides shortcut and navigation features that depend on the current tab and user interaction on links.

Page access is used locally on your device for shortcut features. The only page content sent externally is text you explicitly select and submit for translation. Browsing history, form inputs, and other webpage contents are not sent by the extension.

Permissions

The extension uses the following Chrome permissions:

  • tabs
  • windows
  • activeTab
  • scripting
  • tabGroups
  • notifications
  • host access on pages required by the extension features

These permissions are used only to provide the extension's local functionality.

Data sharing

The extension does not sell user data. Selected text is shared only with the translation provider needed to fulfill a translation you request (Google Translate and/or MyMemory); it is not sent to the developer. No analytics or advertising data is collected.

Contact

If you have questions about this privacy policy, contact the developer through the support or contact details associated with the extension listing.

🇫🇷 Francais

Politique de confidentialite

PK Chrome Shortcuts est une extension Chrome qui fournit des raccourcis clavier et des utilitaires de gestion des onglets et fenetres dans Google Chrome.

Collecte de donnees

PK Chrome Shortcuts ne collecte ni ne stocke de donnees personnelles sur les serveurs du developpeur. Lorsque vous demandez explicitement une traduction, le texte selectionne (1 500 caracteres maximum) est transmis a Google Traduction. En cas d'echec ou si le mode MyMemory seul est choisi, le texte selectionne est transmis a MyMemory (api.mymemory.translated.net). Ces services recoivent le texte pour fournir la traduction et le traitent selon leurs propres politiques de confidentialite.

L'extension n'utilise ni analytics, ni traceurs publicitaires, ni journalisation distante, ni base de donnees externe.

Fonctionnement de l'extension

L'extension utilise localement sur votre appareil les API Chrome pour :

  • gerer les onglets et les fenetres
  • ouvrir des pages internes de Chrome comme les favoris, l'historique, les telechargements, les parametres et les raccourcis
  • reagir aux raccourcis clavier et aux gestes de clic optionnels
  • afficher un badge avec le nombre actuel d'onglets ouverts
  • traduire le texte selectionne uniquement lorsque vous demandez une traduction, via Google Traduction avec MyMemory en secours, ou MyMemory seul selon votre choix

Acces aux pages web

L'extension fonctionne sur les pages web car elle fournit des fonctions de raccourcis et de navigation qui dependent de l'onglet courant et des interactions de l'utilisateur sur les liens.

L'acces aux pages sert localement aux fonctions de raccourcis. Le seul contenu de page transmis a l'exterieur est le texte que vous selectionnez et soumettez explicitement a la traduction. L'extension n'envoie pas l'historique, les champs de formulaire ni les autres contenus des pages.

Autorisations

L'extension utilise les autorisations Chrome suivantes :

  • tabs
  • windows
  • activeTab
  • scripting
  • tabGroups
  • notifications
  • l'acces aux pages necessaires aux fonctionnalites de l'extension

Ces autorisations sont utilisees uniquement pour fournir les fonctionnalites locales de l'extension.

Partage des donnees

L'extension ne vend pas les donnees utilisateur. Le texte selectionne est communique uniquement au fournisseur de traduction necessaire pour repondre a votre demande (Google Traduction et/ou MyMemory) et n'est pas envoye au developpeur. Aucune donnee analytique ou publicitaire n'est collectee.

Contact

Si vous avez des questions sur cette politique de confidentialite, contactez le developpeur via les informations de support ou de contact associees a la fiche de l'extension.
