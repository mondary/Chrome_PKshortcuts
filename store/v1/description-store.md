## Description longue

### FR

**PK Chrome Shortcuts** est une extension Chrome pour piloter les onglets, la navigation et le split view via raccourcis clavier. Les commandes sont gérées nativement par Chrome et regroupées avec emojis dans `chrome://extensions/shortcuts`.

#### ✨ Fonctionnalités clés
- **Badge compteur d'onglets** — l'icône de l'extension affiche le nombre total d'onglets ouverts
- **Split view** — `Cmd + Option + clic` sur un lien pour un split simulé (fenêtres côte à côte) + entrée split view natif Chrome
- **Navigation d'onglets** — précédent/suivant, premier/dernier, dernier onglet actif
- **Actions onglet** — move, pin/unpin, mute/unmute, reload/hard reload, duplicate, unload, detach
- **Pages Chrome** — ouverture rapide de `chrome://bookmarks`, `history`, `flags`, etc.
- **🧹 URL Cleaner** — nettoie les URLs du tracking (utm, fbclid, gclid, etc.) en modes strict/balanced/light/custom
- **♻️ Tab Deduplicator** — détecte et ferme les onglets en double
- **🌐 Traduction inline** — traduit la sélection à la volée (Google + MyMemory)
- **📑 Auto-collapse** — referme automatiquement les groupes d'onglets quand on les quitte
- **💾 Sauvegarde** — import/export/reset de la configuration

### EN

**PK Chrome Shortcuts** is a Chrome extension to control tabs, navigation, and split view with keyboard shortcuts. Commands are managed natively by Chrome and grouped with emoji labels in `chrome://extensions/shortcuts`.

#### ✨ Key features
- **Tab counter badge** — the extension icon shows the total number of open tabs
- **Split view** — `Cmd + Option + Click` a link for a simulated split (side-by-side windows) + native Chrome split view entry
- **Tab navigation** — previous/next, first/last, last active tab
- **Tab actions** — move, pin/unpin, mute/unmute, reload/hard reload, duplicate, unload, detach
- **Chrome pages** — quick open of `chrome://bookmarks`, `history`, `flags`, etc.
- **🧹 URL Cleaner** — strips tracking params (utm, fbclid, gclid, etc.) with strict/balanced/light/custom modes
- **♻️ Tab Deduplicator** — detects and closes duplicate tabs
- **🌐 Inline translation** — translates the selection on the fly (Google + MyMemory)
- **📑 Auto-collapse** — automatically collapses tab groups when leaving them
- **💾 Backup** — import/export/reset configuration
